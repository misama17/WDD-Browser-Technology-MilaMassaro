**dinsdag 17 feb**

Wat heb ik vandaag gedaan?

Ik heb de CSS gedaan voor mijn eerste "stap". Hier ben ik best wel ver mee gekomen. Ik merkte wel toen ik een beetje meekeek met de mensen om mij heen dat mijn vormgeving wel heel erg leek op wat zij hadden. Dus ik wil eigenlijk gaan kijken hoe ik het op een uniekere manier (maar binnen de huisstijl) kan vormgeven.
Ik heb nadat ik wat CSS had geschreven ook gekeken hoe ik het compacter op kon schrijven. Dus ik heb daarna eigenlijk weer veel code herschreven, zodat ik minder regels CSS had.
Ik ben begonnen met me verdiepen hoe ik progressive disclosure kan doen. Ik vond het nog best ingewikkeld eruit zien (of althans veel regels CSS), dus ik moet het nog even goed uitspitten.

Hoeveel tijd heeft dit me gekost?

5 uur totaal.
60 min Weekly Geek.
60 min gewerkt aan vormgeving CSS.
60 min workshop over HTML en vragen beantwoorden.
120 min verder werken aan website (toepassen antwoorden op mijn vragen bij workshop).


Wat heb ik geleerd?

Ik heb wat kleine detail dingetjes kunnen vragen tijdens de workshop. Dus heb over die specifieke vragen geleerd. 
Ik ben begonnen met me verdiepen in progressive disclosure (https://www.silocreativo.com/en/progressive-disclosure-with-css/). 
In mijn Notion heb ik de aantekeningen van de workshop gezet met wat ik heb geleerd.


Wat ga ik morgen doen?

Morgen start weer een nieuw vak, dus afhankelijk van die kick-off...
